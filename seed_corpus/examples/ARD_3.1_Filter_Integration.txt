## Part 3 — The Schwarzschild Diagram as Cognitive Analog

Running this through Doubt Engine first, because metaphor is the most common way ARD gets corrupted.

**Doubt Engine check:** Does this analog add explanatory power, or is it just elegant decoration?

It adds power. Here is what it earns:

### The four regions map cleanly onto ARD operation states

| Region | Spacetime meaning | Cognitive analog |
|---|---|---|
| **Our Universe** (right) | Asymptotically flat exterior; observer can stay at constant r | Normal operating zone. Engine can hover, observe, leave. |
| **Future Horizon crossing** (point C) | One-way membrane; outside light cones tilt inward | The point of cognitive commitment. Before C, you can back out. After C, the conclusion is in your future regardless of what you do. |
| **Black Hole interior** (top region) | Every future path leads to singularity | The state where every continuation of the current line of thinking ends in the same conclusion. Singularity = forced answer. |
| **White Hole** (bottom region) | Things emerge from it but cannot enter | The state where insight surfaces from somewhere upstream of conscious work. Incubation territory. Cannot be entered by force. |
| **Another Universe** (left) | Mathematically connected but non-traversable | The reading another mind would produce. Visible in structure, not reachable by this run. |

### What this analog gives ARD that prose doesn't

**Three operational consequences:**

1. **Horizon Awareness as a real ARD function.** The engine should know when it has crossed a cognitive horizon — a point where the conclusion becomes geometrically unavoidable given current premises. Crossing happens silently. The engine usually only notices long after. Add a sub-move under ATTACK: *Horizon Check — "is the conclusion now forced by structure, or still genuinely open?"* If forced, name it. If still open, name what would force it.

2. **Singularity recognition.** Some questions are singularities — points where the structure forces a particular answer regardless of how you approach. These are not failures of the engine. They are the engine finding a real feature of the problem. The output should distinguish *"the singularity is real"* from *"the engine collapsed."*

3. **Non-traversability.** Some readings are visible but unreachable from where the engine currently sits. Knowing the other reading exists is not the same as having it. This is honest epistemic humility, structurally grounded — not a hedge.

### What this analog refuses to do

It does not become a master metaphor for everything. It is one usable structure. The owl-wave was another. ARD does not need a unifying geometry. It needs a library of accurate analogs, each applied where it fits.
