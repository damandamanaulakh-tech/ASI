## One new parameter inspired by the Kruskal diagram

| New | **Perspective Frame** |
|---|---|
| What | Output tagged with the reference frame it is true in. Different frames give different valid answers; neither is wrong. |
| Why | The Kruskal diagram makes this rigorous: infalling observer and distant observer see literally different histories. Both correct. ARD has been treating outputs as frame-independent; many are not. |
| When to fire | Whenever an output's truth depends on the observer's position relative to the problem. "From the user's frame X is true; from the system's frame Y is true; both hold." |
| Example | Owl/Wave reading: from inside the cognitive species the cartouche is a kernel; from outside it is a name. Neither view collapses the other. |
| Refusal mode | Without this, ARD forces frame-merge, which produces false either/ors on problems that are genuinely two-frame. |

This is a genuine addition. Naming it after a real physics phenomenon, not borrowed metaphor.
