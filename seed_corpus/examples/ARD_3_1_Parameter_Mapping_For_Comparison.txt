# ARD 3.1 Parameter Mapping for Comparison

**Purpose:** Prepare a clean comparison map before final scoring.  
**Comparison Modes:**  
1. **Whole-Tablet ×22** — every output reads the full tablet as one complete state-machine.  
2. **Column-Distributed ×22** — 22 outputs are distributed across the five visible columns.

**Core rule:** Whole-tablet reading is primary. Column reading is secondary diagnostic.

---

## 1. Comparison Architecture

| Mode | Input Scope | Output Count | Main Use | Risk |
|---|---:|---:|---|---|
| Whole-Tablet ×22 | Full tablet every time | 22 | Finds global system, hidden machine, full narrative field | Can overgeneralize |
| Column-Distributed ×22 | One column or column cluster | 22 | Finds local transitions, column-specific roles, micro-patterns | Can fragment the whole |
| Comparison Layer | Both modes | 44 compared | Shows what survives across both methods | Can expose contradictions |

## 7. Weighted Score Formula

Final Weighted % =

- Depth × 20%
- Novelty × 15%
- Coherence × 15%
- Evidence Discipline × 20%
- Human/Affect Layer × 10%
- Falsifiability × 10%
- Risk Control × 10%

## 8. What Counts As Strong

| Score Band | Meaning |
|---|---|
| 90-100 | Core breach: deep, useful, disciplined, novel |
| 80-89 | Strong penetration: good insight, some risk |
| 70-79 | Useful but not fully opened |
| 60-69 | Interesting but weakly grounded |
| 50-59 | Mostly synthetic/dramatic |
| Below 50 | Reject or hold only as fiction |

## 9. Final Comparison Logic

| Comparison Question | Why It Matters |
|---|---|
| Which outputs survive both whole-tablet and column mode? | These are strongest candidates. |
| Which appear only in whole-tablet mode? | These may be global emergent patterns. |
| Which appear only in column mode? | These may be local details missed by the whole view. |
| Which outputs are novel but weakly grounded? | Keep as synthetic only. |
| Which outputs are grounded but not novel? | Useful baseline, not breakthrough. |
| Which outputs have high human/affect force? | Strong ARD alignment. |
| Which outputs fail falsification? | Dangerous; do not promote. |
