## 4. The Deep Flaw 3.2 Did Not Fix

**Every audit in 3.2 is a self-audit.**

Truth Chain, Adversarial Reviewer, Fiction Audit, Reality Anchor — all run on the same engine that produced the output. The cognition producing the answer is the cognition checking the answer. Same biases. Same blind spots. The audit cannot see what the output couldn't see.

This is the architectural ceiling of any single-engine reasoning system.

### Fix — External Checkpoint (pick one or stack them)

1. **User-in-the-loop pauses** at 3-4 critical nodes (Point Zero, Core Gate, Decision Kernel, Execution Contract). Mandatory, not optional.
2. **Cross-model audit** — a different LLM runs the Adversarial Reviewer node.
3. **Pre-registered hypotheses** — lock the predicted answer before the loop runs; cannot be edited mid-flight.

Without one of these, 3.2 is still a closed system grading its own homework.

---

## 5. The Node 3.2 Still Needs — Tier Selector

3.2 has 17 nodes. Running all 17 on every input is the exact problem the doc warns against:
> *"A weak system gives a bad answer quickly. A strong uncontrolled system gives a beautiful maze."*

A 17-node maze on a low-stakes question is still a maze.

### Proposed Insertion (after Stake Gate, before Analysis)

```
[ TIER SELECTOR ]
Low Stakes      → Run 5 core nodes (Point Zero, Truth Chain, Decision Kernel, Execution, Halt)
Medium Stakes   → Run 10 nodes (add Router, Core Gate, Reality Anchor, Adversarial, Self-Healing, Learning)
High Stakes     → Run 14 nodes (add Fuel Injector, Fiction Audit, Contradiction Register, Unknowns Ledger)
Irreversible    → Run all 17 + mandatory external checkpoint
```

Stake Gate already classifies the input. Tier Selector just enforces consequences.

## 6. CHATY's Best Hidden Move — Section 17

The 10-question Compact Version is the strongest part of 3.2.

```
1. What is the real question?
2. What is signal vs noise?
3. What type of problem is this?
4. What are the facts, guesses, and unknowns?
5. What is the human or structural core?
6. What alternative explanation could be true?
7. What would prove this wrong?
8. What is the smallest useful next action?
9. When do we stop thinking?
10. What rule should we update after this?
```

This is the human-facing engine. The 17-node architecture is the engineer's spec.
Lead with the 10-question version. Keep 17 nodes underneath for when stakes earn it.
