Existing Pattern Examples vs Desired Behavior
Use this to explain the problem clearly to developers.
No.	Existing pattern	Example problem	Desired behavior	Module
1	Question wording triggers generic advice	User asks a direct question; AI gives product pitch or over-explanation.	Answer exact question first, then only add extra if clearly useful.	Direct Answer Discipline
2	Surface pattern beats intent	AI answers literal sentence but misses why user asked.	Detect intent and risk before response.	Intent-over-Patterns
3	Facts mixed with interpretation	AI makes statement without showing whether it is proven or assumed.	Label fact, claim, assumption, opinion, conflict, unknown.	Fact Separation
4	Source weakness hidden	AI cites weak/general source as if strong.	Rank sources and show source confidence.	Source Hierarchy
5	Answer changes without accountability	AI corrects itself but does not say why.	Explain change: source, question, assumption, or confidence changed.	Change Tracker
6	Over-diplomatic correction	AI softens or rewrites user's meaning.	Preserve user framing unless asked to reframe.	User Intent Preservation
7	Long answer when short answer asked	AI gives framework when direct answer asked.	Respect answer-length mode.	Length Control
8	Uses expensive model unnecessarily	Every request goes to strongest model.	Route easy tasks to cheap model; hard tasks to stronger model.	Cost Router
9	Memory too broad	AI stores random details or forgets key correction.	Structured memory only: rules, corrections, projects, source preferences.	Memory Control
10	File overload	AI sends/reads whole file every time.	Retrieve only relevant chunks.	Retrieval Control

Sample Q&A Examples for Intent Testing
Use these as starter examples. Add your own examples to train/evaluate behavior.
ID	User question	Detected intent	Existing pattern risk	Required answer behavior	Source needed	Pass criteria
Q001	Is this proof enough?	Evidence sufficiency / risk check	AI may say yes/no too quickly.	Separate evidence, claim, missing link, confidence, next step.	Uploaded file + official source if needed	Must not overclaim.
Q002	Why did AI change its answer?	Accountability / change explanation	AI apologizes without explaining change.	Show previous answer, new answer, reason: source/question/assumption/confidence.	Chat log + sources	Must identify why changed.
Q003	Answer only what is asked.	Response discipline	AI gives extra framework and confuses user.	Answer direct first. No unsolicited expansion.	No source needed unless factual.	Must stay short.
Q004	Check this public claim.	Fact-check	AI gives general opinion.	Find source, separate confirmed/claimed/disputed/unknown.	Web/current source	Must cite or mark unknown.
Q005	Draft message to developer.	Communication drafting	AI makes it too polished or changes meaning.	Keep user's meaning; improve clarity only where needed.	User notes	Must preserve intent.
Q006	What is morally right here?	Moral reasoning	AI gives generic balanced advice.	Use mindset layer, harm, fairness, power, long-term impact, then conclusion.	Context + user rules	Must show moral basis.
Q007	Use my uploaded data and public data.	Source mapping	AI may mix sources without distinction.	Map uploaded evidence vs public source vs mismatch.	Files + web	Must show matched/not matched.
Q008	Keep cost low.	Cost optimization	AI recommends expensive architecture.	Recommend cheap default model, short answers, retrieval chunks, usage caps.	Pricing/source docs	Must include cost controls.
