3. Individual site full flow with reverse loops — revised

Seq	Stage	Main Owner	Connected Owner	Output	Reverse Loop / Change Loop

0	Admin allocates Site Incharge and rights	Admin	CEO	Site Incharge access created	If wrong person/rights → Admin correction
1	Site creation	Site Incharge / Admin	CEO	Site created	If details incomplete → back to Site Incharge/Admin
2	Work order upload	Site Incharge	Admin	Work order uploaded	If amended WO exists → version update
3	Work order / amendment / new request review	AI + Admin + Site Incharge	CEO if needed	Scope, work sequence, key clauses	If unclear → back to Site Incharge/Admin/CEO
4	Gantt chart + WBS generation	System AI	Site Incharge	Draft Gantt + WBS	Site Incharge confirms or revises
5	Client acceptance / confirmation clause tick	Site Incharge	Client / Admin	Accepted / confirmed / pending status	If client not confirmed → hold or reverse
6	Work group breakup	System + Site Incharge	Purchase	Civil, electrical, plumbing, fire, HVAC, etc.	If sequence not practical → revise WBS/Gantt
7	Material list generated from WO + Gantt	System	Site Incharge / Purchase	Material list in sequence	If item not in WO → mark new request/out of WO
8	Site material verification	Site Incharge	Purchase	Required / not required / later required	If mismatch → reverse to material list
9	Purchase TAT + PO + delivery plan	Purchase	Site Incharge	TAT, PO status, expected delivery	If TAT does not match Gantt → Gantt revision
10	Material sequence agreement	Site Incharge + Purchase	CEO if dispute	Material delivery aligned with work sequence	If early/late requirement → Site Incharge reverts to Purchase
11	Final Gantt update after Purchase TAT	Site Incharge / System	Purchase	Confirmed Gantt	If delivery delay → Gantt shifts
12	Subcontractor allocation	Site Incharge	CEO / Finance	Trade-wise subcontractor list	If unavailable → replace/reassign
13	Subcontractor payment schedule	Site Incharge / Finance	CEO if needed	Payment terms and TAT	If cash issue → Finance/CEO loop
14	Site readiness confirmation	Site Incharge	Purchase	Ready / pending list	If material/manpower missing → reverse loop
15	Final pre-start review	CEO / CFO / Purchase / Site	Billing only if required	Go / hold decision	Any issue → return to concerned owner
16	Day 1 project start	Site Incharge	All	Active site	If blocked → reason logged
17	Daily site execution update	Site Incharge	CEO dashboard	Progress, delay, manpower, photos	If delay crosses limit → CEO escalation
18	Material delivery update	Purchase + Site Incharge	Finance if payment hold	PO/TAT/delivery + site receipt	Short/wrong material → Purchase correction
19	Site expense update	Site Incharge	Finance	Site-wise expense entry	Finance verifies under ledger
20	Subcontractor work confirmation	Site Incharge	Finance	Work done / pending / payable	If incomplete → payment hold
21	Billing checklist deployed	Billing	Site Incharge	Full document requirement list	Missing docs → reverse to Site/Purchase/Admin/HR
21A	Billing checklist reverse loop till completion	Site Incharge + Billing	Purchase/Admin/HR	Documents complete gradually	Continues till running/final billing
22	Running PI / measurement / abstract support	Site Incharge + Billing	Finance	PI / measurement / abstract	Mismatch → back to Site Incharge
23	Final bill confirmation by Site Incharge	Site Incharge	Billing	Site confirms bill documents	If not confirmed → billing hold
24	Final billing pack + submission + rejection correction	Billing	Site Incharge / Finance	Submitted / rejected / resubmitted	If rejected → correction loop
25	Payment follow-up	Finance / Owner	Billing support	Payment received / due / pending TAT	Technical query → Billing/Site support
26	Site completion review	CEO / Finance / Purchase / Site	All	Gaps, rate learning, issue changes	Learning goes to owner/finance/purchase decks


Removed from individual active-site flow: master rate comparison, weekly master BOQ update, owner dashboard ledger closure as separate site step.

4. Department-wise responsibility map — revised

A. CEO / Owner deck

Area	CEO control

Multi-site review	All active sites, delayed sites, billing status
Tender costing	Uses master rate list / master BOQ for new tenders
Approvals	High value purchase, rate dispute, delay escalation, TA/DA, finance hold
Payment visibility	Order value vs submitted vs due vs received with TAT
Site progress	Site-wise planned vs actual
Material	Pending / delivered / new request out of WO
Subcontractor	Order value vs submitted vs due with TAT
Expenses	Site expenses + misc expense heads
Escalation	Anything pending beyond defined delay threshold



---

B. Finance deck

Area	Finance control

Site ledger	Site-wise expense, payment, received amount
Pending bills	Submitted / due / received / TAT
Payments received	Against order value and submitted value
Subcontractor payments	Order value vs submitted vs due with TAT
Purchase payments	Vendor payment status
TA/DA	Site-wise TA/DA approval
Misc expense	Sub-head dropdown site-wise + others
Cash flow	Expected inflow and outflow
Client follow-up support	Finance/Owner follows payment, not Site Incharge



---

C. Purchase deck

Area	Purchase control

Material requirement	Taken from WO + Gantt + Site Incharge confirmation
TAT	Delivery timeline for each material
PO	PO pending / issued / hold
Delivery	Pending / delivered / partial / rejected
Material sequence	Material delivered as per Gantt, not dumped at site
Site coordination	Purchase and Site Incharge agree TAT
New request out of WO	Flag separately
Master rate list	Weekly update for CEO tender costing only
Master BOQ	Used for new tender reference, not active site WO correction



---

D. Site Incharge deck

Area	Site Incharge control

Site creation	Can create site after Admin allocates rights
Work order upload	Main owner for active site WO upload
Gantt confirmation	Confirms system-generated Gantt
Client clause confirmation	Accepted / confirmed / pending tick
Site execution	Timeline, finishing, quality, daily progress
Material verification	Confirms required material and timing
Material receipt	Confirms delivered / short / wrong / pending
Subcontractors	Allocation, execution, payment confirmation
Site expenses	Posts expenses as and when done
Running PI	Supports PI / running bill / measurement
Billing support	Confirms billing checklist documents
Final bill confirmation	Confirms before Billing submits



---

E. Billing deck

Area	Billing control

Billing checklist	Deployed near billing stage, not at site start

Summary sheet	Prepare / attach / track
Measurement sheet	Taken from Site/Billing support
Abstract	Prepare / verify
HR compliance	PF, ESI, salary slips, CAR, work policy
Challans	Master list + copies
Handover docs	Handover / installation reports
As-built drawings	Final drawings where required
Client confirmation	Confirmation copy
DLP	Signed DLP copy
Final billing	Bill pack, submission, rejection correction

6. Reverse loop map — revised

Trigger	Goes back to	Action

Site Incharge not assigned	Admin	Allocate person and rights
WO amended	Site Incharge / Admin / Billing	Update WO version
New request out of WO	Site Incharge / CEO / Purchase	Mark as new request, not original scope
Gantt not practical	Site Incharge / System	Revise sequence
Client clause not confirmed	Site Incharge / Admin	Hold tick / confirm later
Material TAT not matching Gantt	Purchase + Site Incharge	Revise delivery plan or Gantt
Material required early/later	Site Incharge → Purchase	Purchase updates TAT
Material delayed	Purchase / Site Incharge	Gantt impact shown
Material short/wrong	Site Incharge / Purchase	Replacement or correction
Delay beyond defined time	CEO level	Escalation
Subcontractor delay	Site Incharge / CEO	Replace/escalate
Site expense posted	Finance	Verify under site ledger
Running PI mismatch	Site Incharge / Billing	Recheck measurement
Billing document missing	Billing → Site/Purchase/Admin/HR	Reverse loop until complete
Bill rejected	Billing / Site / Finance	Correct and resubmit
Payment delayed	Finance / Owner	Client follow-up
Site completed	CEO / Finance / Purchase / Site	Completion review and learning
