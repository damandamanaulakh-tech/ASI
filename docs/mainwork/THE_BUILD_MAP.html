Layer one

The sequence is the shape; the filters are the guard

They are easy to confuse because they share four words. They are not the same thing and they run at different moments — the sequence places the ask before any node fires; the filters review each finding after.

The 8 steps — where a thing sits

3Useused long before it is understood
4Witnesssomeone stops using it and looks

Step 6 is the dangerous one. A name is a voice that gained weight without gaining sources. That is how something climbs off the line — not by lying, by being repeated.

Layer three · Phase 2

Human · AI · Holy Books · ASI — four kinds, one grid, two rubrics

The four are not four systems. They are four sources of parameter values poured into the same container grid, then scored by two different rubrics — so that where they disagree is visible instead of blended.

Human

source

What a person actually does. Your corpus, your trail, the Mahabharata work, the 3-lakh-year human line.

AI

source

What a machine does at the same parameter. Where it matches, where it cannot reach, where it fakes reach.

Holy Books

source

The eternal example. Held as a witness with a period of its own, never averaged with a present fact.

ASI

target

Not a fourth witness — the shape the other three imply. It has no reading of its own; it is what the gaps describe.

Human rubric

planned

Scores a parameter the way a person is scored: by example, wound, pressure, loyalty, what it cost. Eternal example weighs here.

AI rubric

planned

Scores the same parameter by reach, evidence, repeatability, and honest refusal. Present fact weighs here.

Where they differ

the Mask

The gap is the output, not a problem. Two rubrics that disagree on one parameter HALT at ½ and hand you the two readings — the same law as two witnesses.

Why two rubrics and not one blended score: a single score would manufacture one full-weight voice out of two half-weight ones. That is exactly the move the ½ forbids, and it is the move that would quietly make the engine's answers not yours.

Layer four · Phase 3

How one brain works — a node opened up

There is no central model. There are 95 small ones, each with its own memory, each narrowing the same way.

Any node can loop back to any earlier node. It is a network, not a pipeline — which is why the drift meter matters: in a network, one loud node is invisible until you measure it.

What every node reads and writes

Corpus memory

yours

Your own files and words. The only place new content enters. Read on every run.

Wisdom memory

eternal

The examples that keep applying. Grows slowly, deliberately, and is never overwritten by a single run.

Live fact

present

What is true right now, with an expiry. Never allowed to masquerade as eternal — and never the other way round.

Write-back

after the run

Each node stores what it learned into its own brain — that is where "wiser every use" actually happens, and where drift would accumulate unseen.

Layer five · the measurement

The ½ line — has one voice become the author?

This is the whole Riemann walk spent as one instrument. A voice growing like √n stays one of the crowd forever. A voice growing faster ends up being the answer while the engine still prints five contributors.

What the meter returns

σ per node

A voice planted at σ=0.72 came back 0.7201 and named. The four built on the line came back within 0.0007 of exactly ½.

What it refuses to do

honest limits

Accuracy is set by run length, not code. Too short a run and it says UNDER-RESOLVED with the number it would need — it does not round into something reassuring.

Read this line if you read nothing else: drift does not announce itself with a wrong answer. It produces a confident answer with the crowd still visible in the margin.

The one real cost

node_work.py

Today it asks a model to do the per-node thinking. Replacing that with a retrieval-and-rules lane over your corpus is the largest single item in the plan — not a config flag.

The trade you should make with open eyes: with no model at all, the engine stops generating language and becomes retrieval, rules and composition over your own text. It will select, match, filter, connect, rank and assemble — and it will not write a sentence that isn't yours. For a clone of your mind, that may be exactly right.
