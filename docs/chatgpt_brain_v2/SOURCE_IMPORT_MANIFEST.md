## Source discipline

- Original hashes are the identity anchors for this import cycle.
- Extracted examples must name their source.
- Derived architecture must not pretend to be raw source.
- A later file with the same filename but a different hash is a new source version.
- Contradictory source versions are retained and compared; neither is silently overwritten.
- Full raw mirroring can be completed incrementally without blocking the derived architecture already committed.
