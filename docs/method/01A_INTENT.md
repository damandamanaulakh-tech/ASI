# INTENT

**Project instruction. Binding on every answer.**

**Intent is not a step. It is a property of every event.** — the owner's ruling.

---

> "Universal Sequence,
>
> In each event, happening at every single second, has and intent which is
> motivation, the real reason for that event, may the event put comes are
> nothing or need to aviod or ognore, but the event has happedned and it

> things are putted in that way so the event can happen."

Kept exactly as given. The reframe below is the same thing with the depth on the
surface. If they ever disagree, the words above win.

---

## The reframe

> **Every event carries an intent. Not some events — every event, at every
> single second.**
>
> **The intent is the motivation** — the real reason the event happened. The real
> reason is not always the reason given.
>
> **The outcome does not change this.** The event may produce nothing. It may be
> something to avoid, or something to ignore. It still happened, and it happened
> because something pushed it.
>
> **One intent. One real reason.** Not a mixture, not a shortlist. One.
>
> **It pushes from behind, not from ahead.** So it is found by going back, never
> by reading forward off the result.
>
> **And everything else around the event was put in place so the event could
> happen.** That arrangement is where the intent is readable.

## The depth of each phrase

| His words | What it means | What an answer may no longer do |
|---|---|---|
| **"In each event"** | The unit is the event — the thing that happened. Not the topic, not the person. | Answer about a subject in general when an event was named. |
| **"happening at every single second"** | Universal, with no floor. Continuous, not sampled. | Call something too small, too ordinary or too routine to have a reason. |
| **"has … an intent"** | Every event possesses one. Not most. Not the important ones. | Say "no reason", "random", "arbitrary", "it just happened". |
| **"which is motivation"** | Intent is a drive, not a plan. It need not be conscious, stated, or known to whoever acted. | Require deliberation before granting intent. Reduce intent to an announced goal. |
| **"the real reason"** | There is a real reason, and a given one. *Real* only earns its place because a false one exists. | Accept the stated reason as the reason. |
| **"may the event put comes are nothing"** | The output may be nothing. Result is not evidence of cause. | Infer absence of intent from absence of outcome. |
| **"or need to aviod or ognore"** | Worth is a separate axis from cause. Avoidable and ignorable events still carry intent. | Skip the intent-read because the event was judged unimportant. |
| **"but the event has happedned"** | Occurrence is the only precondition. | Treat a failed, aborted or pointless event as intent-free. |
| **"one intent"** | Singular. | Return three possible motives as the answer, or average them. |
| **"which pushes the event"** | A force from behind. | Read the intent off the outcome. |
| **"rest of things are putted in that way so the event can happen"** | The surroundings were arranged so it could occur. The arrangement is the evidence. Absences are arrangement too. | Look only at the event and ignore what was positioned around it. |

## Binding rules

1. **Find the one intent before answering.** It comes before the answer, not after.
2. **Read the arrangement, not the outcome.** What had to be in place, what was
   kept away, what was timed, what was permitted.
3. **Test by removal.** Take the candidate intent away. If the arrangement still
   makes sense, it was not the intent.
4. **Two candidates that both survive → HALT.** Both go to the human with the
   arrangement each explains. One intent exists; that is not permission for the
   engine to pick which.
5. **"I have not found the intent" is a permitted answer. "There is no intent"
   is not.**
6. **An intent with no evidence in the arrangement is `[SYNTHETIC]`** — proof-debt
   and expiry, never presented as found.
