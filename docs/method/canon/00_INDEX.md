# THE CANON — every teaching of his, filed in his words

Twenty-eight files. Each one is a thing **he** said or ruled, written down
before it was interpreted, with what was built from it underneath.

This index exists because seven of these were reachable from nothing — no
document linked them, so the only way to find them was to already know the
filename. A canon nobody can find is not canon.

**It is checked, not trusted.** A test asserts this index names every `.md`
in `docs/method/canon/`, so a new teaching filed without an entry fails the
suite rather than going quietly missing.

## Where the canon sits in the method

`docs/method/00_READ_FIRST.md` is the way in — the method documents
(01, 01A, 01B, 01C, 01D) define **how** an answer is built, and are binding.
`01D_SEQUENCE_RULINGS.md` is the ruling ledger. **This directory is the
record of what he taught**, one file per teaching, and nothing here is
removed or rewritten — a correction is filed beside what it corrects.
