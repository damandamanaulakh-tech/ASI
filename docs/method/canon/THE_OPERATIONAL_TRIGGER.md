## 1. WHAT THE THIRD COLUMN IS, AND WHY IT IS NOT A THIRD NAME

Until this, every node in the architecture carried **two columns**: the human
name he wrote and the computer parallel, because ASI is the verified Human↔AI
connection and one column alone cannot link.

Both of those answer the same question — **what is this**.

His third column answers a different one: **when does it fire.**

| | |
|---|---|
| Thermoregulation | `Temp > $T_{max}$ triggers cooling loop / frequency scaling.` |
| Sleep Architecture | `Idle timer > Threshold triggers ACPI S3/S4 state.` |
| Semantic Memory | `Vector similarity search (Cosine similarity $> 0.85$).` |
| Nociception (Pain) | `Hardware fault generates non-maskable interrupt (NMI).` |

A name is a **noun**. A trigger is a **condition** — and a condition can be
*evaluated* where a noun can only be read. That is what makes it a state vector
and not a label: it names the measurement, the threshold, and what happens at
the crossing.

His own sequence law already said this at a different level — *thresholds live
on edges and answer "why now"*. This column is that law written at container
level.

## 4. GRADED MATCHING — 36 PLACED · 3 PROPOSED · 9 HELD

A match is graded, never boolean, and the grade travels with it:

| grade | route | count |
|---|---|---|
| `EXACT` | the normalised names are identical | 18 |

| `SAME WORDS` | the same words under different endings — *Somatosensation* → *Somatosensory Perception* | 8 |

which is a different thing entirely. A weak match that placed silently would
carry his trigger to the wrong container. So it is **PROPOSED** and waits for
his word, and a test proves no proposed match reaches a container's trigger.

He forbade placeholders and empty slots. He also forbade invention. A derived
trigger is built from **two real sources and nothing else**:

1. **the container's own machine column**, authored with the split, and
2. **its spine step**, which fixes the SHAPE of the firing.

The second is the principled part. Where a container sits on his spine
determines what kind of event fires it:
