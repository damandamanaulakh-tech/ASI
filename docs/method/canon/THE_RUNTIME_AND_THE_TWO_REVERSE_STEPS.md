**Both are reverse-direction, and both sit BEFORE decomposition.** That is the

## 2. WHERE THE METHOD CAME FROM — HIS OWN DOC

`docs/mainwork/THE_REVERSE_WALKS.md` already carried the method, in his frame:

> A reverse walk starts at the thing as it stands today, finished and named,
> and descends: what must have been true *immediately* before this, without
> which this could not stand?

> **THE REMOVAL TEST.** Take the step away. Does the step above it still stand?
> If it still stands, it was never a dependency — it was a neighbour, and it is
> dropped.

> Where the walk stops: at something nobody made. That is GROUND.

So step 3 is the removal test made executable, and step 2 is the "finished and
named" thing the descent starts from. Nothing methodological was invented for
this phase.

## 3. STEP 2 — DECLARE END (`prior.declare_end`)

* **A PULL is not a PUSH.** "So that / in order to / wanted to" name a target
  AHEAD — an end. "Because / since / due to" name a reason BEHIND. Both are
  kept; a reason is **never promoted** to a target.
* **His word outranks the parse.** `his_end=` takes it, labelled HIS
  ASSIGNMENT, with the parsed candidates kept beside it.
* **Two ends at the same grade HALT.** Not blended, neither preferred — and the
  halt ships with `separates_them`: for each pair, the evidence that would
  separate them (a preparation, a cost paid, an order given that only one of
  the two needs). The halt is itself a prediction generator.
* **An unnamed end is UNNAMED, never absent** — with the three things that
  would name it. "There is no reason" is not an available answer.
* **WHY THIS MATTERS is not a sentiment** — it is the list of the four steps
  that consume the end downstream (3, 11, 12, 18), with the statement that
  three of them come after decomposition, so a wrong end is not caught later,
  it is *inherited* later.

## 4. STEP 3 — REVERSE TO PRIOR REALITY (`prior.prior_reality`)

* **Three grades, never merged:** STATED (the source says so), ENTAILED (the
  event's own grammar requires it — an actor that did not exist cannot act),
  ASSUMED (I put it there).
* **The descent CANNOT assume.** `ASSUMED` exists only through an explicit
  `assume()` call that stamps `[SYNTHETIC]` with proof debt and expiry — his
  rule 5 made structural. A test runs the whole pipeline and asserts zero
  ASSUMED rows.
* **The removal test is his, verbatim.** ENTAILED rows survive by construction;
  STATED rows survive only if the top actually leans on them. A dropped prior
  is kept as a NEIGHBOUR with the reason — nothing is deleted.
* **Where the lexical test is least trustworthy, it says so.** On his own rain
  sentence, *"pointed it in the air"* shares no word with *"thought its
  raining"* — yet the first causes the second. Seeing that needs knowledge of
  the world, which the descent is forbidden. The drop stands and is **FLAGGED
  FOR HIS REVIEW**, never quietly reversed.
* **Ground is claimed only when reached.** "Something nobody made" — read
  through his own node classes (HUMAN BODY is the nearest thing this core has
  to something nobody built). Most single-sentence descents stop on something
  built or on something unknown, and the module says which.

## 6. THE HONESTY RULES THE PIPELINE KEEPS

* A step that cannot bite on one ask **says so instead of faking**: R-F-R on a
  single unrepeated ask reads thin (one occurrence is not an arrangement),
  maturity reads UNTESTED, the verdict reads UNKNOWN. An eighteen-step run on
  one sentence SHOULD end open.
* **Step 17 prepares and does not write.** It composes the rows a write would
  append and evaluates his five write conditions — on a bare run two of five
  are honestly unmet (*link map created* is Phase D itself; *origin distance
  recorded* is not yet carried). Writing past an unmet gate is what the gate
  exists to stop. The HTTP route does not expose writing at all.
* **Detection is not choice.** His sixteen packs are checked for evidence words
  the ask itself gives; `chosen` stays None — his SP-22/SP-23 pair reads the
  same sentence two ways and chooses neither.
* The combination step runs the **same cross-role gate** that cut 2,627 to
  2,119, scoped to the ask's own arrangements.
